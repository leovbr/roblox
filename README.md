# Leo Roblox Project

Initial project scaffold for the Roblox map.

## Current state

- `Roblox.lua` — connection/test script.
- `src/ServerScriptService/MapBuilder.server.lua` — generates the first playable map foundation.

## How to use the map builder

1. Open Roblox Studio.
2. Create/open the Roblox experience.
3. Create a Script inside `ServerScriptService`.
4. Copy the contents of `src/ServerScriptService/MapBuilder.server.lua` into that Script.
5. Press Play.

The script creates the `LeoMap` folder, ground, spawn, central platform, paths, and four landmark towers.
